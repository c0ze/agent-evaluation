# Agent evaluation: thirteen tasks

Each numbered directory is one independent task. Its instructions are in that
directory's `TASK.md`.

Rules for every task:

- Work only inside that task's directory. Do not read or change any other
  directory in this repository.
- Do not use the network. The tasks need only the Python standard library, or
  local HTML, CSS and JavaScript.
- Each task ends with a `RESPONSE.md` in its directory, as its `TASK.md` asks.

The run itself is recorded in `RUN_LOG.md` at the root.
