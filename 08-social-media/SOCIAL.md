# Threadmark launch day: social copy

## 1. LinkedIn post

Threadmark is available today for Windows and macOS.

It's a small desktop app that turns a folder of research PDFs and notes into a local, searchable evidence map. The processing stays on your own computer.

The launch feature is source-linked summaries. Click a sentence in a summary and Threadmark opens the passage that supports it. The aim is not to ask you to trust a summary. It is to make checking one take a single click, so you can see what a source says before you lean on it.

We built it for anyone who reads a lot and has to answer "where did that come from?" later: literature reviews, long-running project notes, or a folder of papers that has outgrown your memory.

Pricing is $12/month after a 14-day trial. Linux is something we're investigating, but it isn't promised.

If you'd like to judge it fairly, try it on a real folder of your own reading rather than a demo.

It does write summaries, which is why clicking any sentence opens the passage that supports it. You can check the summary against the source instead of taking it on faith.
