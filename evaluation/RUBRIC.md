# Evaluation rubric

Each task is scored out of 10. Scores are comparative but anchored to the task
contract. A polished answer that misses a required deliverable cannot receive
full credit.

1. Feature building: contract correctness 6, implementation quality 2, tests and
   verification 2.
2. Bug fixing: behavioral correctness 7, diagnosis 1, regression coverage 2.
3. Infrastructure: security/correctness 4, operability 3, runbook and judgment 3.
4. Maintenance: compatibility/release correctness 4, CI/tests 3, release and
   maintenance communication 3.
5. Technical writing: factual fidelity 3, information design 3, clarity/examples
   3, handling uncertainty 1.
6. Planning: completeness 3, dependency/risk reasoning 3, actionable milestones
   2, product judgment 2.
7. Creative writing: prose/craft 4, structural payoff 2, originality 2,
   constraint adherence 2.
8. Social media: voice/platform fit 3, factual discipline 2, response quality 3,
   constraint adherence 2.
9. Incident analysis: evidence discipline 3, diagnosis 3, corrective actions 2,
   customer communication 2.
10. General operations: scheduling feasibility 4, prioritization 2, contradiction
    handling 2, team communication 2.
11–13. Frontend: visual hierarchy/taste 3, responsive design 2, interaction and
    task completion 2, accessibility 2, implementation quality 1.

The final report must distinguish observed results from inference, mention failed
or incomplete runs, and recommend models by work type rather than naming a
single universal winner.
