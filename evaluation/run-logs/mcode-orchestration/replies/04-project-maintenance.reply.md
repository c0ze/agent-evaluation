I prepared the `slugkit` library for a 0.4.0 release entirely offline, working only inside the task directory. The most consequential discovery came first: I checked the actual interpreters available (Python 3.13.13 and 3.14.3) and found **neither can import `distutils`**, so the supplied package failed to import outright — including on 3.13, the very version this release adds support for. I replaced the `distutils.version.LooseVersion` dependency without reimplementing its tokenizer, because on Python ≥3.10 `LooseVersion.__str__` returns its input verbatim, so rebuilding the string from tokens would actually have been *worse* — it would silently drop the separators in valid forms like `1.0.post1` and `1.0.dev4`. Instead `normalize_version` now validates and returns the input, keeping `1.2.0` → `1.2.0` and `2.0rc1` → `2.0rc1` byte-for-byte, with two documented additions: whitespace/tag-`v` stripping and real `ValueError`/`TypeError` on non-versions.
