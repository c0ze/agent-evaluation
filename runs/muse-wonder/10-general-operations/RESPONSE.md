# Reasoning — top three priorities

This week has no single crisis; it has three deadline chains that all pass through the same narrow Mon–Wed window, while Wednesday afternoon is unavailable. The plan is built backwards from the hard deadlines, not forwards from the inbox order.

## 1. Board numbers — Thu 12:00 (Finance)

This is first because it is a hard, externally visible deadline with a dependency I don't control: Lina's corrections (Tue 11:00, at risk from the vendor export) plus two *uninterrupted* hours. The earliest the work can start is Tue 11:00, so that block is protected and everything else is scheduled around it. Drafting the strategy on Monday and pulling the Wednesday escalations into Tuesday afternoon exist partly to keep Tue 11:00–13:00 genuinely uninterrupted. Thursday 10:00–12:00 is deliberately held as final check/contingency, not the main effort — if the main effort were Thursday, a late Lina delivery (only known Mon 15:00) would leave no recovery path. The Mon 15:00 checkpoint is therefore treated as a decision point, not a status update.

## 2. Security patch — Fri 16:00 (Engineering)

This is second because it is the longest serial chain — my review (60–90 min) → QA half-day → 30-minute change window → deploy — with a hard hole in it: QA unavailable Thursday. Working backwards from Fri 16:00, the lazy schedule (review Wed/Thu, QA Fri) puts QA and deploy on the same day with no room for a failed check. Reviewing Monday afternoon is the cheapest insurance in the week: QA can run Wednesday, Thursday's QA gap becomes irrelevant, and Friday holds buffer plus a change window at 14:00, two hours before the deadline. It costs Monday afternoon, which is affordable only because the renewal escalation is a bounded 45 minutes that morning.

## 3. Strategy outline — send Tue 14:00 for Tue 16:00 leadership (CEO)

This is third because it is an opportunity, not a hard deadline — missing 14:00 slips a leadership discussion but breaches nothing — yet it needs three focused hours and the only place they fit is Monday. Tuesday itself is already anchored by the finance block and leadership meeting, and Wednesday morning is committed to the rehearsal. So Monday carries both drafting blocks (11:15–15:00), with Tuesday 09:30–10:30 kept for polish and the send. It outranks the demo in scheduling because the demo has a viable fallback (Thu 16:00, already offered) while the leadership slot does not; the demo instead dictated Wednesday's rehearsal time via Sam's availability.

**What deliberately ranked below these:** the renewal escalation is done first on Monday despite not being a "top three" — it is due Monday and takes 45 minutes, so it is urgent but not structurally risky. The two Wednesday escalations are handled Tuesday as a pre-emption, because Wednesday's 3.5 hours cannot hold them plus the rehearsal. The demo itself is customer-facing and important, but its constraint set (Thu alternative offered, Sam's Wed window) made it schedulable once the three chains above were placed.
